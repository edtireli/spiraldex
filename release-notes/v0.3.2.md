# SpiralDex v0.3.2 — Gateway Pairing

The pairing dialog now accepts an HTTPS address with a gateway path:

```text
https://edspiral.duckdns.org:8443/spiraldex
```

Save keeps the prefix, and all health, scan, and progress requests use it. An optional trailing slash is normalized. Existing direct Mac addresses still work. Invalid tokens and fingerprints now identify the field to correct; non-JSON missing-route replies explain that the gateway route needs attention.

**The gateway must already route `/spiraldex` to your Mac host.** This APK fixes address validation and requests; it does not add a route to the separate Spiral Chat gateway. DuckDNS by itself does not configure that route. Certificate pinning, encrypted token storage, and the API allowlist remain enforced.

Install `SpiralDex-0.3.2.apk` over your existing app to keep your discoveries and pairing details. No Mac host update is required for this client fix. Mac host, demo, corresponding source, and SHA-256 checksums are included.

Verified with 64 Java URL/routing checks, native Android Save/reopen, prefixed HTTPS health/scan/status requests, direct-host compatibility, missing-route errors, blocked redirects, certificate pinning, and release lint. See [verification](https://github.com/edtireli/spiraldex/blob/v0.3.2/TESTING.md). Public shared-gateway connectivity and a scan on a physical phone are not established by these controlled tests.
