# Your field unit, ready to discover

SpiralDex now opens directly to its optical scanner. Take a photograph, watch the unit trace its subject and consult the Dex, then receive a completed card. Type, rarity, HP, field ratings, notes, and finish are selected automatically; the card joins your archive immediately.

Swipe **right** through Scanner → Card archive → Kana library. The D-pad does the same. There is no scrolling home feed, starter shelf, or bottom navigation.

- Inspect any entry for its reading, examples, pronunciation, and corrections.
- Real discoveries and the existing Mac pairing survive an APK update.
- Starter demonstration cards are removed from the real collection.
- This version includes an updated Mac host for live progress and card metadata. Replace the companion files and restart it, using the same private identity directory.

Android 9+, an awake Mac on the same network, Python, and an installed Ollama vision model are required for new scans. The public demo uses prepared discoveries and never uploads photographs. Rarity and stats are collectible game attributes. Generated Japanese and object labels can need correction. This is an early preview, with no iOS release yet.
